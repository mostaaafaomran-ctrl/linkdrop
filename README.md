# LinkDrop

Link-in-bio page builder, one HTML file, host anywhere.

**Live: https://mostaaafaomran-ctrl.github.io/linkdrop/**

Fill in your links, pick a color, download one clean HTML file and host it free.

## Features

- Live phone preview while you type
- 5 color themes, Arabic RTL detected automatically
- Output is a single HTML file with no scripts or trackers
- Share link keeps your page in the URL itself

## Run locally

No build step. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Privacy

Everything runs in your browser. Nothing is uploaded and there is no account.

## العربية

ابني صفحة روابط بملف HTML واحد وارفعها مجانًا على GitHub Pages.
